# Sai Tailors Management System

A Flask + SQLite starter implementation based on the uploaded UI reference.

## Features included

- Admin-only login
- Premium tailoring-style shell
- Home customer search
- Today's delivery notification count/panel
- New customer/order form
- Shirt and pant selection
- Shirt types and measurements
- Pant measurements
- ₹350 per shirt and ₹350 per pant
- Live total / paid / balance calculation
- Delivery date
- Pending and completed orders
- Today's sale
- Weekly sales
- Monthly revenue
- Expenses
- Responsive layout

## Run locally

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open:

`http://127.0.0.1:5000`
